## Gate A — Windows host preflight

Use the authorized Windows host only. Do not mutate the current production bundle until all checks pass.

1. Verify production is idle:
   - no active publisher job
   - no active GPM automation lease
   - no unresolved deployment operation
2. Capture:
   - current `/api/app-info`
   - current production release path
   - current production artifact/checksum if available
   - current DB/data backup
3. Verify rollback bundle still launches before replacing anything.
4. Fetch source SHA without changing a dirty working tree.

Recommended isolated checkout:

```powershell
$SourceSha = 'e447505d56bc1cfb1afbfc36036a7622f5601183'
$ReleaseWorktree = 'D:\Claude\Homestay\fbpost-v6131-release'

Set-Location 'D:\Claude\Homestay\fbpost'
git fetch origin
git worktree add --detach $ReleaseWorktree $SourceSha
Set-Location $ReleaseWorktree
if ((git rev-parse HEAD).Trim() -ne $SourceSha) { throw 'SOURCE_SHA_MISMATCH' }
if ((Get-Content VERSION -Raw).Trim() -ne '6.1.31') { throw 'VERSION_MISMATCH' }
```

## Gate C — canonical portable build

From the exact source worktree:

```powershell
Set-Location 'D:\Claude\Homestay\fbpost-v6131-release'
powershell -ExecutionPolicy Bypass -File .\BUILD_PORTABLE.ps1

$Zip = '.\release\artifacts\FB-Automation-Portable-v6.1.31-Windows-x64.zip'
$ShaFile = "$Zip.sha256"

if (-not (Test-Path $Zip)) { throw 'ARTIFACT_MISSING' }
if (-not (Test-Path $ShaFile)) { throw 'CHECKSUM_MISSING' }

$Actual = (Get-FileHash $Zip -Algorithm SHA256).Hash
$Expected = ((Get-Content $ShaFile -Raw).Trim() -split '\s+')[0]
if ($Actual -ne $Expected) { throw 'ARTIFACT_SHA_MISMATCH' }

Write-Host "PRODUCTION_EQUIVALENT_RC_SHA256=$Actual"
```

The Windows-host artifact hash is expected to differ from the GitHub source-only RC because it includes `runtime/`. Record the new hash; do not compare it for equality with `BDCC...`.
